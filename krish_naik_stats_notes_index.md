## Recommended Study Order

1. Descriptive Statistics (Central Tendency → Dispersion → Percentiles → Skewness)
2. Probability Distributions (Bernoulli → Binomial → Poisson → Normal → Standard Normal)
3. Probability Rules (Addition, Multiplication, Bayes)
4. Inferential Statistics (CLT → Estimates → Hypothesis Testing → Z-test / T-test → Errors)
5. Applied topics (Correlation, Regression, Performance Metrics)
